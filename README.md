# Lab_1_Huffman_code

Тема  -  Реализация алгоритма сжатия текста при помощи кода Хаффмана.

Файл рассматривается как последовательность байтов.

Алгоритм кодирования/декодирования:
Построения кода Хаффмана для исходного файла

struct Node { // Структура узла для построения дерева
    char symbol;
    struct Node* left;
    struct Node* right;
    Node(char symbol = 0, Node* left = nullptr, Node* right = nullptr) {
        this->symbol = symbol;
        this->left = left;
        this->right = right;
    }
};

Узел может быть символом, либо нет. Если символ, то symbol = коду символа, иначе 0. Отличие узла символа от узла не символа - для узла символа указательи left и right == nullptr одновременно

void delete_tree(Node* root); - удаление построенного дерева внутри функций encode и decode

void Hoar_sort(size_t* arr, Node** arr_purpose, int l, int r); - функция для рекурсивной косвенной сортировки
(сортировка массива arr, и одновременно с ни соответствующих элементов arr_purpose (элементы с одинаковыми индексами - соответсвующие)) подмассива от l до r по алгоритму Хоара

void Hoar_sort(size_t* arr_sorting, Node** arr_purpose, int length); - функция для косвенной сортировки по алгоритму Хоара
(сортировка массива arr, и одновременно с ни соответствующих элементов arr_purpose (элементы с одинаковыми индексами - соответсвующие)) подмассива от l до r по алгоритму Хоара

int fill_Tab_code(Node* ptr, char* code, char** Tab_code); - заполнение таблицы кодов Tab_code строкой кода code, которая формируется внутри функции в процессе реккурсивного левого обхода дерева
(ptr изначально указывает на корень дерева)

Дополнительная информация, которая записывается в файл (последовательно, начиная с начала файла):
(Длина таблицы - 1) - 1 байт (-1 - т.к. если таблица длиной 0, то она не пишется в файл и сам файл вообще пустой)
Ассоциативная таблица с частотой встречаемости символа в исходном файле (на самом деле ее часть, так как если символ встретился 0 раз, это лишняя информация для записи) - формат символ (байт) за ним его частота (size_t 8 байт)
(Запись и чтение size_t через fwrite/fread => в байтовом представлении байты записаны в обратном порядке (но каждый байт внутри себя в правильном порядке))
3 бита - длина хвоста
Затем сам кодированный текст

int encode(char* filepath, char* filepath_new);
На вход передаются пути к файлам какой файл сжимать и куда (в какой) файл сохранять (поддерживаются абсолютные и относительные пути)

int decode(char* filepath, char* filepath_new);
На вход передаются пути к файлам какой файл сжимать и куда (в какой) файл сохранять (поддерживаются абсолютные и относительные пути)

Функции кодируют и декодируют файл по алгоритму описанному выше.

Если возникает ошибка в процессе выполнения, то функция закрывает уже открытые файлы и удаляет второй созданный внутри нее файл(если он был создан). Если при этом возникает ошибка, 
то функция только сигнализирует об этом посредством соответсвтующего кода возвращаемого значения

При неверных входных данных для декодирования функция на будет либо файл с мусорным значением, дибо возникнет ошибка во время выполнения функции

Коды возвращаемых значений для функций encode и decode

Код | Описание ошибки
1   | Успешное кодирование/декодирование файла
0   | Ошибка при чтении, записи, премещении по файлу или другие ошибки
-1  | Ошибка при открытии файла
-2  | Ошибка при закрытии файла
-3  | Ошибка при удалении файла
